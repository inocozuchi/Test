# 無音カメラ

シャッター音・録画開始音を出さずに動画を撮るための、iPhone向けWebアプリです。車窓撮影のように、長時間放置して録画する使い方を想定しています。

公開URL: https://inocozuchi.github.io/Test/ (Safariで開き、共有ボタンから「ホーム画面に追加」すると全画面で使えます)

## 使い方

1. 画質を選んで、黒い丸ボタンを押すと録画が始まり、画面が真っ黒になります。
2. 録画中に画面を **5回タップ** するとメモ画面が開きます。ここから写真・動画・PDFも見られます。
3. **10回タップ** で録画が止まり、保存画面になります。保存したい範囲を1秒単位で選べます。
   - 「写真アプリに保存」: 約300MBずつに分けて、共有メニューの「ビデオを保存」で保存
   - 「ファイルアプリに保存」: 1本の動画としてファイルアプリの「ダウンロード」に保存(進み具合を表示)
4. 録画データは「削除」を押すまで端末内に残ります。途中でアプリが落ちても、ホーム画面の一覧から保存できます。

## 構成

- `index.html` — アプリ本体(HTML/CSS/JavaScript を1ファイルにまとめている)
- `mp4split.js` — 録画(断片化MP4)から選んだ区間を切り出し、単独で再生できるMP4に作り直す
- `sw.js` — 圏外でもアプリを開けるようにするサービスワーカー。録画をファイルアプリへ少しずつ書き出す処理も担当。ファイルを変えたら `VERSION` を上げる
- `vendor/pdfjs/` — PDF表示用の [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174(Apache-2.0、`LICENSE` 同梱)
- `test.html` — カメラの対応解像度・フレームレートを調べる検証用ページ

## 仕組みの要点

- 写真・動画はカメラ映像を直接録画するので、OSのシャッター音は鳴りません。
- 録画データは1秒ごとに端末内(IndexedDB)へ書き込みます。サーバーには一切送りません。
- iPhoneのSafariは共有メニューに渡すファイルを全部メモリに読み込むため、写真アプリへは約300MBずつに分けて渡します。
- 容量は「標準」でiPhone純正カメラのH.264(互換性優先)と同じデータ量です。SafariはHEVCで録画できないため、純正カメラのHEVC(高効率)の約2倍になります。
